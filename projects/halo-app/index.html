Halo Taxi, a ride-hailing app in Flutter

Customers pick a car class, see the fixed fare before they order and follow the driver on the map. One code base runs on both iPhone and Android. Try it on the phone: any 4-digit code signs you in.

  • Phone sign-in with a code from the dispatcher, no SMS costs at launch
  • Five car classes, each with its own tariff and an up-front fare
  • Live status, arrival time, driver, car and plate
  • Clean architecture: screens, state and API layer kept apart
  • Flutter
  • Dart
  • iOS
  • Android
  • REST API
